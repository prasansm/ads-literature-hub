# Contributing

Contributions that improve coverage or organization are welcome.

## Entry format

```markdown
- [Paper title](stable primary link) — Authors, *venue year*. Why it matters. `tag`
```

Prefer a publisher, conference, author, or arXiv page over a secondary summary. Use tags sparingly: `seminal`, `production`, `survey`, `recent`, `theory`, or `measurement`.

## Before opening a change

- Put the resource in the component where its main contribution belongs; cross-link instead of duplicating it.
- Include authors, venue/year, and a one-sentence annotation.
- Check that the link resolves and is not already present.
- Separate established work from very recent preprints.
- Do not add promotional posts when a primary or authoritative source is available.
